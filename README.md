## ⚡ About Me

<img align="right" width="245" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="Programming animation"/>

I am an **Electronics and Communication Engineering student** focused on developing my skills in **Embedded Systems, Firmware Development, Electronics, and IoT**.

My interest lies in understanding how hardware and software interact — from microcontroller programming and sensor interfacing to debugging electronic systems and developing connected-device prototypes.

I enjoy learning through practical implementation, experimenting with hardware, and understanding the engineering decisions behind a working system.

- 🎯 **Primary Focus:** Embedded Systems and Firmware Development
- 🔌 **Hardware:** ESP32, STM32, Arduino, and Raspberry Pi Pico
- 💻 **Programming:** C, C++, and Embedded C
- 🌐 **Interests:** IoT, sensor networks, and hardware-software integration
- 🧪 **Approach:** Build, test, debug, document, and improve
- 🎬 **Content:** Sharing technical learning through Code Mode On

<br clear="right"/>

> *My goal is to understand systems at both the hardware and firmware levels — and turn that understanding into practical engineering solutions.*
