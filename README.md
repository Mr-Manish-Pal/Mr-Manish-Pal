## About Me

<img align="right" width="250" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="Animated programming illustration"/>

I'm an **Electronics and Communication Engineering student** passionate about embedded systems, electronics, microcontrollers, and firmware development.

I enjoy exploring how hardware and software interact — from interfacing sensors with microcontrollers to developing firmware and connecting individual components into practical systems.

For me, engineering is not limited to writing code. It also means understanding circuits, investigating unexpected behavior, debugging problems, and improving a design through experimentation.

- Embedded systems and firmware development
- Electronics troubleshooting and hardware integration
- ESP32-based projects and connected devices
- Microcontroller programming and sensor interfacing
- Practical learning through building and testing

**My goal:** To become a skilled Embedded Systems Engineer capable of developing complete hardware-software solutions.

## How I Approach Engineering

<div align="center">

<img src="https://img.shields.io/badge/01-UNDERSTAND-123B70?style=for-the-badge" alt="Understand"/>
<img src="https://img.shields.io/badge/02-DESIGN-087EAA?style=for-the-badge" alt="Design"/>
<img src="https://img.shields.io/badge/03-IMPLEMENT-2563EB?style=for-the-badge" alt="Implement"/>
<img src="https://img.shields.io/badge/04-DEBUG-6D5DFB?style=for-the-badge" alt="Debug"/>
<img src="https://img.shields.io/badge/05-IMPROVE-123B70?style=for-the-badge" alt="Improve"/>

</div>

I aim to follow a practical and structured development process:

1. Understand the problem and expected behavior.
2. Select suitable hardware and define the system architecture.
3. Develop firmware with clear and maintainable logic.
4. Integrate the hardware and software components.
5. Test the system, investigate faults, and refine the implementation.
6. Document the design, limitations, and future improvements.

My long-term focus is to strengthen both low-level programming and electronics fundamentals so I can build systems that are not only functional, but also understandable and maintainable.
