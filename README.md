## ⚡ About Me

I am an **Embedded Systems & IoT Engineer** currently pursuing my **B.Tech in Electronics and Communication Engineering**. I bridge the gap between complex hardware architectures and efficient software code.

With practical experience across multiple microcontrollers and a deep understanding of internet-of-things protocols, I design, prototype, and deploy production-ready embedded solutions.

* 🚀 **Current Focus:** Deep-diving into **FreeRTOS** (Dual-Core ESP32 Programming) & Advanced Power Optimization.
* 🛠️ **Hardware Veteran:** Worked with **30+ industrial and consumer sensors** (Voltage, Current, Biometric, Environmental).
* 🌐 **Content Creator:** I share my engineering knowledge on YouTube via my channel **Code Mode On**.

## 🏆 Featured Projects

### 🚪 [GateX — ESP32 Gate Automation](https://github.com/Mr-Manish-Pal/GateX)
* **Tech Stack:** ESP32, Ultrasonic Sensor, OLED Display, LEDs, Buzzer, Push Button.
* **Description:** An ESP32-based gate automation prototype featuring distance-based status detection, OLED expressions, LED indicators, a buzzer alert, and a dedicated mute button.

### 🌐 [NEXUS-6 — ESP32 Sensor Network](https://github.com/Mr-Manish-Pal/NEXUS-6)
* **Tech Stack:** ESP32, Sensors, Wi-Fi, HTTP, Local Web Dashboard.
* **Description:** A multi-node sensor-network project designed around one ESP32 host and six ESP32 client nodes, with sensor readings intended to be monitored through a local web dashboard.

### 📟 [IoT-Based Smart Energy Meter](https://github.com/Mr-Manish-Pal/IoT-Smart-Energy-Meter)
* **Tech Stack:** ESP32, ZMPT101B, PlatformIO, Blynk IoT Cloud, STM32, Raspberry Pi Pico.
* **Description:** An IoT-based energy-monitoring project focused on measuring electrical parameters and displaying readings through a monitoring dashboard.
